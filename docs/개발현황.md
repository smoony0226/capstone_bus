# 개발현황

기준: 2026-10-03. BUS1 공통 차체 치수 뷰어의 첫 버전.

## 구현 상태

- 사용자 실측 9개 항목을 적용했다. 모델의 닫힌 외곽은 940×180×230mm이며 앞축 190mm,
  뒷축 600mm(앞범퍼 기준), 축거 410mm, 바퀴 지름 83mm를 사용한다.
- 제공 외형 사진 5장을 반영한 녹색 외장, 검은 창문, 승강문, 바퀴·휠, 지붕부를 표현한다.
- 정투영 아이소메트릭·전면·측면·상단, 원근 시점, 회전·확대·이동을 지원한다.
- 외형 / 축·바퀴 치수선 전환, 카메라 토글, 초기화를 지원한다.
- 배터리 덮개 개방 비율, 탈거·장착, 교환부 확대를 간단한 3D 표현으로 구현했다.
- 하단에 실측 표, OAK·IMU·엔코더 정보, PIDNet·YOLO 역할, Jetson–UART–ESP 제어 흐름,
  관제·스테이션 비전·로봇팔 설명과 사진 확대를 제공한다.
- 치수 데이터·메시 모델·치수 표시·UI 상태를 분리했다. 기존 racer_ws에는 변경이 없다.

## 검증 경계

- Node 치수 계약 시험 2/2 PASS. 모순된 축 거리·바퀴 둘레·비유효 수치가 거부된다.
- Chromium 브라우저 시험 PASS: 실제 메쉬 외곽, 5개 시점, 레이어, 배터리 동작과 초기화,
  사진 5장·확대, 390px 모바일 레이아웃, 회전, WebGL 실패 안내.
- Vite 프로덕션 빌드 PASS. Three.js 청크가 500kB를 넘는 빌드 경고가 남아 있다.
- 패키지 감사: 취약점 0. 개발 서버는 Vite 6.4.3을 사용한다.
- [검증 기록](verification/2026-10-03-viewer.md) 및 해당 폴더의 화면 캡처 참조.

## 미해결 항목과 다음 우선순위

1. 배터리 덮개 대상·힌지 방향은 추가 상부 사진으로 보정 가능하다. 현재 동작은 탈착 설명용이다.
2. 센서 중심 좌표·센서 외형 치수·후방 OAK 모델명은 실측 전이다. 실제 좌표 치수선을 추가하지 않았다.
3. 지붕 기본 높이와 세부 형상은 사진 가정이다. 제조사 CAD 정밀도를 의미하지 않는다.
4. GitHub 저장소 [smoony0226/capstone_bus](https://github.com/smoony0226/capstone_bus)를 비공개로 생성했다.
   GitHub Pages 공개 배포는 아직 수행하지 않았다.
